Explain why a rendering engine, device or power state produces a symptom, using the
`engine-behaviour` skill. Read its `SKILL.md` first.

Use it for a symptom on one engine, device or power state — a stutter, a snap, a stuck hover,
a zoomed page, a video that will not autoplay. Name the mechanism the engine applies, what it
recomputes, throttles or refuses to run, and give a safer way to build the same result.

It is a reference library, not a procedure, and it is platform-neutral: the mechanisms hold
for any site on any stack.
