# Parity review profiles

Profiles control breadth, never condition equivalence.

| Profile | Required comparisons | Evidence |
|---|---|---|
| `targeted` | one exact node/live selection at the reported width, state and content plus one adjacent risk condition | paired captures, live measurement, node identity, verified finding |
| `standard` | every declared route/component family at its canonical desktop and mobile frames; default and interactive states named in the map | frozen plan, repeat captures, measurements, paired images, manifest |
| `deep` | standard plus in-between widths, long/empty data, themes/locales, reused instances and relevant interactions | stable repeat capture, control-state proof, difference masks where useful, reviewed evidence |
| `launch` | every required map cell and every approved source variant that can ship | hash-bound attestation and explicit `ran`, `partial`, or `not-run` coverage for the full denominator |

Do not substitute a similar frame, nearby node, different content, or renamed
canvas without recording a new comparison contract. A missing canonical canvas
or unresolved node is a design-source blocker, not permission to judge by memory.
